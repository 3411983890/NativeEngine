光照系统走的是"可回退的近似"路线：不追求 Lumen 级的全局光照，而是把每一分预算花在肉眼能看见的地方——局部灯投影、froxel 雾与光轴、一次反弹 DDGI、会自阴影的体积云。

五项交付

1. 光照正确性

cooked 材质的 key 光只写入独立直射通道，合成时阴影只乘一次。DXR 从 Environment.keyDirection 取太阳/月亮方向，表面与体积共用同一参数；场景拒绝零方向。帧常量按在途帧独立分配，避免 CPU 覆盖仍在使用的光照数据。

2. 局部灯投影

点光与聚光分别查询自己的世界空间可见性，阴影只作用于该灯的漫反射与高光。按亮度、范围和距离选重点灯，保留稳定 ID、25% 选择滞后与八帧进出淡化——没有滞后的灯选择会以帧为单位闪烁。

档位表面阴影灯上限静态阴影缓存
平衡2最多 4 盏，六面 128² 径向深度图
高档4同上；静态几何或灯的位置/范围变化时重建

车辆与门通过当前 TLAS 查询动态遮挡，不触发静态缓存重建。PCF 按接收面在各采样射线上的真实距离比较，控制自阴影条纹。

3. Froxel 雾与光轴

对数深度网格，范围到 96 m；高度雾与最多八个带软边界的局部密度盒相加。太阳/月亮通过 froxel 世界坐标查询 DXR 可见性；每格按实际散射贡献选四盏局部灯，其中前两盏可查询体积阴影。HG 相位 + Beer–Lambert 积分，在 HDR 空间按 scene × T + L 合成。

"lighting": {
  "fogVolumes": [
    { "center": [0, 2, 8], "extent": [20, 6, 8], "density": 0.03 }
  ]
}

extent 是完整尺寸，不是半长；density 按距离倒数计量。稳定光照重投影并裁剪历史，移动车灯每帧重算——否则车灯光柱会被写进长期历史，拖出一条尾巴。

4. 天空 IBL 与 DDGI

同一份程序化天空同时生成漫反射 SH、GGX 预过滤立方体和 split-sum BRDF LUT。DDGI 用 16×8×16 探针、4 m 间距、每探针 64 条射线；命中读取实例变换、纹理、材质颜色、表面状态、自发光和带遮挡的直接光。

八面体图集存辐照度与距离一、二阶矩，配合探针迁移、无效探针排除、可见性加权插值和变化自适应历史累积。天空可见比例单独保存——否则天空补光会被算两次。

5. 体积云

持久 64³ 三维噪声 + 天气纹理，世界空间风场平移。沿光方向次级积分提供自阴影，128² Beer 透射图向表面和雾投影，三档衰减项近似多次散射。云在半分辨率积分，按不透明深度截断，用首个云样本距离、风运动与前帧矩阵重投影，最后深度感知重建。切镜、场景参数变化和资源重建都会让历史失效。

场景开关

"lighting": {
  "quality": 1,
  "localShadows": true,
  "ibl": true,
  "ddgi": true,
  "cloudShadows": true,
  "temporal": true,
  "maxShadowLights": 2
}
字段作用
localShadows局部灯投影总开关
ibl天空 IBL（SH + 预过滤立方体）
ddgi探针全局光照
cloudShadows同时控制云自阴影与向地面投影
temporal雾与云的视图历史；DDGI 仍用自己的探针历史
maxShadowLights0–4，且仍受质量档上限约束

明确不是

不是 Lumen：没有表面缓存、没有软件光追 GI、没有无限反弹。DDGI 只有一次反弹，覆盖相机附近约 60×28×60 m。没有体积雾的多次散射解，云的三档衰减项是近似。10k 光源的 cluster / light tree / ReSTIR 设计仍在研究文档里，没有实现。

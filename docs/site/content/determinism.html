四条硬约束

规则含义如何强制
禁止进程级随机源engine/native/ 里不许出现 std::rand、srand、std::random_devicetools/determinism.ps1 静态扫描，违规即失败
禁止读墙上时钟不许 std::time、GetTickCount、QueryPerformanceCounter同上；帧间隔只能由宿主传入 update(input, dt)
随机必须命名Lua 用 ctx:random(name, bound)；原生用 registry().stream("<name>")新增消费者不会移动其它流已依赖的序列
渲染不得反馈进模拟分辨率、调试视图、DXR / Mesh 开关不改变摘要作为证据断言，每次 verify 都跑

摘要编码固定：原生数值按 1e-4 网格量化；玩法组件、Lua 显式状态与队列按有序 JSON 序列化后取摘要；非有限状态拒绝提交。

组成

组件实现作用
HasherFNV-1a 64，纯整数运算跨编译器一致；quantized() 做网格量化
Streamxoshiro128**，splitmix64 播种next / unit / range + 计数器
Registry按名字持有流（std::deque，引用稳定）fingerprint() 覆盖种子、流名与计数器
Game::digest()汇总模拟状态tick、玩家位置/速度、相机角、动画相位、玩法标志、刚体状态、损伤与断裂计数

摘要不包含：渲染状态、窗口尺寸、GPU 时序、墙钟时间。它们不是模拟输入。

CLI

build/NativeGPU.exe --smoke --no-watch --frames 240 \
  --hash-log reports/x.log --seed 20261020
参数作用
--seed <u64>本次运行种子（默认 20261020），重置所有命名流
--hash-log <path>逐帧摘要日志，\n 行尾、无 BOM

报告新增 determinism 段：seed、fixedStepHz、ticks、hashLines、finalHash、rng.streams[]、rng.fingerprint。

证据

powershell -File tools/determinism.ps1 -Frames 240

跑 5 次冒烟：基线两次、640×360 一次、--debug-view mask 一次、--seed 7 一次，然后断言：

  • 两次基线摘要日志逐字节相同；
  • 分辨率与调试视图不改变摘要；
  • 240 帧 = 480 tick（120 Hz 固定步长，2 tick/帧）；
  • 报告的 ticks / finalHash 与日志末行一致；
  • 两个命名流（gameplay、cosmetic）已注册，fingerprint 为 16 位十六进制；
  • 换种子后 fingerprint 变化；
  • 静态扫描通过。

回放与黑匣子

build/NativeGPU.exe --record reports/run.replay
build/NativeGPU.exe --replay reports/run.replay --replay-strict
参数作用
--record <path>记录输入、dt、内容指纹与初始快照
--replay <path>重放；摘要不符时报告差异
--replay-strict任何不符立即失败
--stall-frame / --stall-ms注入卡顿，验证黑匣子定位能力
--blackbox-stall-ms黑匣子专用的卡顿注入

回放 v4 保存源码构建指纹、场景身份、Lua / 组件 / 动画内容契约，以及 .initial.json 初始模拟快照；逐帧记录精确 dt，支持变帧率录制。正式录制/回放关闭自动重载，回放在模拟前验证内容。

证据：tools/replay.ps1 25 项，240 帧 0 不符；篡改可定位到具体帧；anomaly sidecar 可回放。

承诺范围

只承诺这些
  • 同机、同构建、同内容、同输入 → 逐字节相同。
  • 不承诺跨平台、跨编译器优化级别的浮点一致。
  • 摘要覆盖模拟状态，不覆盖材质、灯光、场景文件——它们由场景哈希单独覆盖。
  • 旧版本日志可解析，但不同模拟契约下的摘要不能当作兼容性保证。

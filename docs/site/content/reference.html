命令行

运行与场景

参数说明
--scene <path>加载场景，默认 assets/courtyard.scene.json
--character <path>加载角色资产（character.json）
--smoke无交互冒烟模式，跑固定帧数后退出
--frames <n>冒烟帧数（240 帧 = 480 tick）
--no-watch / --watch关闭 / 打开场景热重载轮询
--report <path>运行报告输出路径
--seed <u64>确定性种子
--hash-log <path>逐帧摘要日志

读报告的姿势

先看 environment.worktreeDirty 与 staleBuild：任一为 true，数字就只是"当时那棵树的快照"。再看 capabilities.implemented.*，最后才看性能数字——能力为 false 时的 P95 没有意义。

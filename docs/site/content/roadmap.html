下一步

编辑器：先验证，再决定

内嵌实时视口的前置不是"写一个合成器"，而是先单独验证成熟容器的共享纹理导入能力：复制次数、同步等待、输入延迟、缩放与最小化、设备丢失恢复。没有这组测量，不做内嵌视口。定制 Chromium 路线已暂缓，不再作为前置。

植被：三个硬前置

10k 木本 + 50k 草的目标写在 .developmentAgent/vegetation/VEGETATION-PLAN.md，但它现在还不能开工，因为缺三样：

  1. 任意网格绘制路径——现在只有单位立方体顶点/索引缓冲
  2. GPU 驱动的实例化 + 间接绘制——现在每个 item 一次 DrawIndexedInstanced(..., 1, ...)
  3. alpha-test / 双面 / 顶点 UV 的植被材质——现在用世界空间平面投影 UV

另外阴影需要分块代理，不能让 10k 棵树逐棵进 TLAS（上限 1024）。

地形：P0 可以马上做

见地形系统。结论是视距 120 m 下不需要 LOD，一块 128 m 瓦片就够。P0（高度图格式 + CPU 采样）没有前置依赖，是当前性价比最高的一块。

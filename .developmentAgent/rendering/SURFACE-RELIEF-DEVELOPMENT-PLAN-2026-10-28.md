# 地面高度表现与真实置换开发方案

日期：2026-10-28。状态：P0–P4 已实现；P0–P2 已在目标项目启用，P3/P4 已构建并测量但按性能与误差结论默认关闭。实施记录见第 11 节。

## 1. 目标与实施顺序

先让当前石板湿泥场景在近景、斜视和移动相机时呈现可辨认的砖缝深度，再建立可复用的静态地面置换能力。推荐顺序为：高度数据契约 → POM 视觉深度 → 多层高度表面 → 静态几何置换 → 可选碰撞高度场。

第一轮交付覆盖 P0–P2，解决当前“看起来还是一张平面”的主要视觉问题。P3 增加真实轮廓和投影；P4 单独提供物理地面支持。各阶段分别验收，不再把“读取了高度图”当作已经实现表面起伏。

| 模式 | 视角移动时的凹凸视差 | 改变外轮廓 | 砖缝真实投影 | 改变碰撞 |
| --- | --- | --- | --- | --- |
| 当前法线 + 高度混合 | 无高度视差 | 否 | 否 | 否 |
| POM 视差遮蔽 | 有，受角度和采样预算限制 | 首版不支持 | 可选局部高度场自遮蔽，不能代替几何投影 | 否 |
| 静态几何置换 | 有 | 是，取决于网格密度 | 是，需所有投影路径使用置换网格 | 单独启用高度场碰撞后才改变 |

## 2. 已核实的现状

- `shaders/material_layer_sampling.hlsli` 采样高度并计算 `height * heightScale + heightOffset`；`material_layer_blend.hlsli` 只用它调整层覆盖率。
- `shaders/material.hlsl` 在原始表面坐标上读取各层，没有地面 POM 射线步进或几何高度位移。
- `engine/material/layered.mjs` 对字段做严格校验，现有 `nativegpu.layered-material/1` 的 `heightScale` 是混合数值，不能直接解释成米。
- `engine/native/material_layer_gpu.hpp` 的 GPU 层布局固定为 512 字节，扩展必须同步 JS 打包、原生和 HLSL，不能只改单端。
- 当前工程石板法线强度为 0.65、泥巴为 0.85；增强法线只作为调材质辅助手段。
- `host/texture_asset.hpp` 当前运行时格式列出 RGBA8/BC1/BC3/BC5。原始高度为 16-bit，但本次预览高度已量化至 8-bit。
- 场景为 16×16 米地面，石板每 3 米规则重复；泥巴是覆盖整块地面的随机旋转、尺度和偏移图集。两者不能套同一份 UV 偏移。
- 当前四层实际上是两种物理材质的成对表达：Stone ORM / Stone 独立通道、Mud ORM / Mud 独立通道。配对层不能被误算为四次物理堆高。
- 原生物理目前以方块及可选凸包为基础；本方案不假设已有可直接复用的通用三角网格或高度场碰撞。

## 3. 数据和编辑器契约

新增版本化高度表现配置，建议放在分层材质 v2 的材质级 `surfaceRelief` 中。v1 继续原样读取，默认关闭高度表现，只有显式迁移才生成 v2。以下为拟定字段，实施 P0 时冻结名称和取值范围：

| 字段 | 含义 |
| --- | --- |
| `mode` | `off` / `pom` / `bakedDisplacement` |
| `heightSource` | 指定层高度，或经过显式映射的合成高度表面 |
| `amplitudeMetres` | 高低差的物理尺度，与现有混合高度缩放分开 |
| `referenceHeight` / `invert` | 归一化参考面及高度方向，明确白高黑低约定 |
| `minSteps` / `maxSteps` / `refineSteps` | 搜索步数与交点细化次数 |
| `fadeStartMetres` / `fadeEndMetres` | POM 向普通法线表现连续淡出 |
| `grazingFade` | 极低视角渐隐，防止 UV 偏移爆炸 |
| `selfShadow` / `shadowSteps` | 可选主方向光局部高度遮蔽，默认关闭 |
| `displacementBake` | P3 使用的地面网格分块、密度、LOD 和缓存配置 |

高度定义为 `heightMetres = (height01 - referenceHeight) * amplitudeMetres`。POM 首版使用顶部参考面，只向表面内部搜索，避免无几何支撑的正向突出；P3 才允许有明确上下界的双向置换。

材质级表面模式互斥，避免同一高度既烘焙进顶点又被 POM 再次应用。以后确需微细节叠加时，另设只包含残差高度的明确来源。

编辑器显示“混合高度”和“表面深度（厘米）”两组独立控制。提供关闭/POM/几何切换、实时前后对照、高度/UV 位移/步数热图；支持保存、重载、撤销和打包。参数修改走现有材质事务服务，不直接修改 GPU 数据。

## 4. P0：高度数据与最小参考

1. 对两套高度图核对方向、有效范围、周期边界与对应法线；先看直方图和参考灰度图，不自动拉伸每块砖的高度。
2. 为高度纹理增加线性 R16_UNORM 运行时格式与版本化格式码，同步 cook、原生加载、D3D12 上传、mip、字节统计、复制打包和校验；旧纹理继续可读。R16 不支持时按能力报告明确回退至 RGBA8，不静默降精度。
3. 保留原始 16-bit 数据。POM 普通 mip 以平均高度保持稳定，保守范围数据若用于提前跳过，必须另建 min/max 层级，不能把平均 mip 当作保守边界。
4. 建立平面、线性坡面、凹槽三种小型解析参考，CPU/GPU 对比交点和 UV 偏移；幅度为零时恢复旧采样路径。

完成标志：高度方向和尺度可解释；格式读写/打包往返一致；开启开关但幅度为零时，画面与旧路径一致。

## 5. P1：单高度来源的 POM

### 5.1 求交与一致采样

- 在 `material.hlsl` 分层取样之前执行高度射线搜索。按观察角分配步数，先有界线性步进，再插值或二分细化，不使用单次 UV 偏移代替遮蔽求交。
- 用世界位置、UV 导数与几何法线建立局部表面关系，处理物体缩放、UV 旋转和镜像；POM 用几何法线构造基底，避免法线贴图制造自反馈。
- 搜索输出统一的命中位置/表面切向位移，而不是把高度图 UV 偏移直接加到所有纹理。
- 对每个有效 UV 集，通过世界空间导数到该 UV 的局部映射传播位移，再施加每个纹理槽已有的 UV 变换。不同 UV 集的退化矩阵有明确回退和诊断；保留 wrap/clamp 语义，不能给整幅泥巴图集加 wrap。
- 同一命中点读取基色、法线、ORM、独立 AO/粗糙度/金属度、发光、高度以及泥巴分布遮罩，防止砖缝颜色、湿润高光和泥巴边缘滑动。顶点色遮罩首版采用像素局部常值近似，并明确此限制。
- 在动态循环前取得导数，使用 `SampleGrad` / 显式 LOD 控制纹理过滤。初版以原始表面梯度作为稳定近似，对高频、细化失败、UV 接缝和极低视角做淡出；后续再评估命中梯度修正。

### 5.2 首版能力边界

先支持静态、不透明、可建立有效 UV 基底的分层材质光栅路径。蒙皮、透明、无光照和不支持的绘制路径必须报告能力或明确降级；不能显示配置已生效却使用旧路径。

第一步指定石板高度为驱动，泥巴跟随同一表面命中点采样，但此阶段还没有独立泥巴体积。P2 验收通过后才替换当前预览的最终版本。

首版不写像素深度。像素深度偏移需要同时解决深度预通道、接触阴影、物体交界及已有后期/时间历史消费者的一致性，单独作为后续开关，不并入基础 POM。

## 6. P2：石板与湿泥共享物理高度表面

当前场景优先选择“离线合成高度 + 一次 POM 搜索”，避免每一步都完整采样四层全部 PBR 通道。

1. 在地面规范坐标中，以保留精度的石板高度、泥巴高度、随机泥巴覆盖构建版本化的合成高度资产。石板仍按 3 米规则重复；泥巴沿用现有随机种子、旋转、尺度及整幅图集映射。
2. 显式配置高度组和归一化高度到米的映射。两套 Stone 表达属于同一高度组，两套 Mud 表达属于另一组，ORM 与独立通道配对不累加厚度。
3. 石板凹槽与泥巴填充使用物理高度合成规则：石板表面为基底，泥巴顶面不得在可见覆盖区穿入基底；以平滑遮罩过渡。现有 `LayerHeightCoverage` 仍用于材质覆盖，不直接当作以米计的几何高度。
4. 烘焙高度表面及材质覆盖使用一致来源和缓存键，包含原图哈希、UV 变换、尺度、种子、遮罩及版本。编辑后标记缓存失效，原子更新高度与覆盖，避免新颜色配旧高度。
5. 先以 2048² 高度作默认、4096² 作近景高档比较；根据砖缝投影宽度决定分辨率。16 米宽 2048² 约 7.8 毫米/像素，不能宣称能稳定解析任意毫米细节。
6. 一次求交后再按现有独立 UV 读取四层颜色与 PBR。保持所有原始贴图参与既有材质流程，高度计算不重复生成四层物理结构。

通用动态多层高度留作扩展：若实现实时复合搜索，每步只读取必要的高度和遮罩，并有独立预算；不能默认把四层完整 PBR 取样放入搜索循环。

### 当前场景初始调参范围

| 项目 | 初始候选值，均需实机复核 |
| --- | --- |
| 砖面至砖缝深度 | 1.5–3 厘米 |
| 泥巴厚度变化 | 0.3–1.2 厘米，受覆盖和基底高度约束 |
| 石板法线强度 | 先恢复 1.0，再对照 0.8–1.2；不重复放大同一低频起伏 |
| 平衡档 POM | 8–24 步 + 2 次细化 |
| 近景高档 | 16–48 步 + 3 次细化 |
| 距离渐隐 | 从 6 米开始，到 14 米关闭，按实际镜头调整 |
| 极低视角 | 在几何 N·V 为 0.05–0.15 区间连续减弱 |
| 主光局部自遮蔽 | 基础验收通过后再选配，4–8 步，远景关闭 |

主光自遮蔽只影响相应直接光照，不把遮蔽量直接乘到所有环境光；仍须检查与来源 AO 的重复变暗。先通过同光照 A/B 验收，再调整大气光照，避免用暗缝掩盖错误的高度。

## 7. P3：静态地面真实置换

采用确定性的静态网格烘焙作为第一版真实几何方案，暂不把通用 GPU 曲面细分或虚拟微多边形系统列为前置依赖。

- 将地面拆为独立网格块，按合成物理高度移动顶点；先支持平面地面，不直接推广到任意封闭或蒙皮网格。
- 第一轮比较每 2 米一块、每边 64/128 单元两档：16×16 米地面约 52 万/210 万三角形，实际按细缝宽度和性能选档，计入阴影成本。
- 生成确定性 LOD，处理邻接裂缝、边界法线和 LOD 高度过渡；外边缘生成封边。接缝共用采样位置和 mip 规则，不能靠遮挡裂缝通过验收。
- 更新网格边界、剔除、拾取和编辑器选中轮廓；颜色、主光/局部光阴影、深度及已启用光追加速结构使用同一几何版本。任何暂未接入的通道都列为限制。
- 使用高度梯度与原始法线分频合成，先以几何法线对照，避免几何宏观起伏和贴图法线重复强化。
- 置换后关闭相同高度的 POM；远景选择几何 LOD 与法线表现，阶段切换必须验证高度和外观连续。
- 缓存写入用户项目目录；源场景保留可编辑配置和原始材质引用，烘焙产物不写回引擎资源目录。

完成标志：近景侧视有真实轮廓；低角度主光产生正确投影；从地面边缘、接缝和 LOD 边界观察无开裂。

## 8. P4：可选高度场碰撞

视觉高度和碰撞分别启用，默认保留当前稳定碰撞，编辑器明确显示是否跟随地形。

需要支持静态地面高度采样、法线查询，以及与当前角色扫掠、踏步、落地检测和刚体接触的集成；不能仅修改角色脚底 Y 值当作碰撞完成。高度场是单值地面，不覆盖洞穴或悬挑。

物理网格使用经过误差约束的简化高度；砖缝小凹陷可平滑，明显台阶要保留。报告最大表面误差，并验证行走/奔跑/跳跃、斜向跨砖缝、物体落地及接触稳定性。失败时回到旧碰撞并显示状态。

## 9. 性能、验收与交付

### 性能门槛

现有 1440×900 实测全景/近景 GPU P50 约 48.44/78.39 毫秒，当前场景本身尚不能承诺 60 FPS。新增效果必须比较同机器、同分辨率、同相机的关闭/开启差值。

- 平衡档目标：全景 POM 增量不超过基线 15%，近景不超过 25%；这是开发门槛，不是已达到的性能。
- 预热后取至少 120 帧，报告 P50/P95、活动像素、理论最坏高度采样数、纹理字节和实际步数热图。普通材质采样引用统计不能冒充 POM 动态采样次数。
- 超预算时依次关闭自遮蔽、降低步数、提前距离淡出、降低合成高度分辨率；不得通过隐藏砖缝深度换取无说明的性能达标。
- R16 的单幅 2048² 基层约 8 MiB、完整 mip 约 10.7 MiB；4096² 完整 mip 约 42.7 MiB，需纳入现有约 234.7 MiB 分层纹理预算。

### 增量验证

新增入口拟放在 `.incrementalTesting/rendering/surface-relief*.mjs`；P4 相关验证放在 `.incrementalTesting/simulation/`。真正新增入口时再同步 package.json、commands.json、README 和受影响 CI 调用；本次文档不创建空测试入口。

1. P0：数据契约、旧版本迁移、无效参数、16-bit 保真、mip/上传/打包、GPU 布局。
2. P1：解析凹槽求交；正视/斜视/极低角度；UV 旋转、镜像、独立 UV、非均匀缩放；零幅度和无贴图回退。
3. P2：规则石板与随机泥巴对齐；四层配对不重复堆高；原图全部参与；缓存失效；运行、编辑器和打包一致。
4. P3：网格高度数值、封边、LOD 裂缝、边界、拾取、深度和投影一致。
5. P4：仅运行受影响的地面/角色/刚体专项。遵循仓库要求，未经用户另行要求不运行全量测试、`npm test`、`npm run verify` 或完整 CI。

## 11. 实施结果（2026-10-28）

### 11.1 P0 高度数据契约与 R16

- `engine/material/layered.mjs` 新增 `nativegpu.layered-material/2` 与材质级 `surfaceRelief`，字段名称按第 3 节冻结；v1 原样读取、哈希不变，`migrateLayeredMaterialToV2` 显式迁移且默认 `mode: off`。旧 v1 场景不会自动写入 v2。
- 原生解析器 `engine/native/material_layer_asset.hpp`、场景加载器、`GpuMaterial` 与 HLSL 布局同步；`GpuSurfaceRelief` 为 96 字节，材质记录由 364 字节扩展到 460 字节，JS/C++/HLSL 三端一致。
- 新增 NGTEX 格式码 5（线性 R16_UNORM，仅允许 `height` 语义）：cook 支持 16-bit 灰度 PNG、平均 mip、R16 容器；原生校验、D3D12 上传/字节统计、材质打包校验与能力报告同步。旧 8-bit 高度图仍回退 RGBA8，并在能力报告中计数 `rgba8Fallback`。
- 解析参考位于 `engine/material/surface-relief.mjs`；平面/坡面/凹槽与稠密根求解对照见 `npm run test:surface-relief`。

### 11.2 P1 POM

- `shaders/material_layer_sampling.hlsli` 增加有界线性步进 + 二分细化、世界导数到各 UV 集的位移传播、距离/掠射淡出、可选主光自遮蔽，以及深度/UV 位移/步数调试量。
- `material.hlsl` 在分层采样前执行 POM，统一命中点采样四层颜色/PBR；平面 UV 轴选择改用世界法线，修复非均匀缩放网格把地面误判为侧面。
- 编辑器新增“表面深度（厘米）”面板、v2 迁移按钮与三组热图；能力报告新增 `layeredMaterials.surfaceRelief`（materials/pom/baked/selfShadow/r16Textures/r16Bytes/rgba8Fallback/pixelDepth）。
- 首版边界：仅静态不透明光栅分层路径；不写像素深度；顶点色遮罩仍为像素局部常值近似；自遮蔽只乘到直接光。

### 11.3 P2 共享物理高度

- `tools/surface-relief.mjs bake` 以石板 3 米规则重复 + 泥巴整幅图集 + `mud_spread` 遮罩合成 2048² R16 高度；泥巴顶面以 `max(stone, stone + mud*coverage)` 约束，石板/泥巴各只取一个高度组，四层配对不重复堆高。
- 目标项目结果：`ground_composite.height.ngtex` 11,184,938 字节、12 级 mip；石板深度 2.5 cm、泥巴 0.8 cm，总幅度 3.3 cm；合成范围 0.000015–0.7922，`referenceHeight = 0.7922`。缓存键含源纹理哈希、映射、深度和版本；报告写入项目 `reports/surface-relief/bake.json`。

### 11.4 P3 静态置换（已实现，默认关闭）

- `tools/surface-relief.mjs mesh` 生成 `assets/meshes/ground_surface_relief.mesh.json`（512 单元、271,361 顶点、528,384 三角形、约 29.8 MB），含世界米制 UV、确定性法线与外沿封边；报告 `reports/surface-relief/mesh.json`。
- 渲染器单网格上限从 262,144 顶点/1,048,576 索引提升到 1,000,000/3,000,000，与加载器预算一致。
- 同机同分辨率（1440×900，AMD Radeon 890M）实测：关闭 67.99 ms、最终 POM 配置 68.53 ms（+0.8%）、512 单元网格 199.63 ms、256 单元 140.14 ms、128 单元 107.16 ms。几何置换档位均超出第 9 节 25% 门槛，因此目标项目默认保持 POM；网格与替换脚本保留为可选路径。
- 限制：运行时无网格 LOD 选择；DXR 阴影仍使用 OBB 代理；3.9 cm 网格不能解析毫米砖缝。

### 11.5 P4 高度场碰撞（已实现，默认关闭）

- 物理新增 `physics::Heightfield` 单值地形采样/法线；刚体窄相位按盒足迹五点采样生成接触；角色竖直移动、踏步与穿透修正改为查询地形，地形体不再作为盒参与角色扫掠。
- 场景实体新增 `heightfield` 引用（R16 资产、origin/size、min/max、maxError、enabled），加载器校验哈希与格式；编辑器显示是否跟随地形。
- 目标项目碰撞资产 1025² R16、2.8 MB；与 2048² 合成高度的最大表面误差 6.33 mm（预算 5 mm，`budgetMet:false`，砖缝小凹陷被平滑、明显台阶保留）。视觉与碰撞独立开关，默认 `enabled:false` 以保持原稳定碰撞与 POM 外观一致。
- `npm run test:heightfield` 覆盖采样、台阶保留、刚体落地与静止接触；角色行走/奔跑/跳跃、斜向跨砖缝仍应在启用前按第 9 节做专项验收。

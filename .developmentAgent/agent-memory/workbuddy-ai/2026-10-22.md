## F4b 凸网格渲染 / F4d 断面材质 / 关节进场景格式（深夜）
- **F4b**：新增 `engine/native/convex_mesh.hpp`（`ConvexVertex` 32B 与渲染器立方体同布局、`ConvexMesh`、`VoronoiPackage`/`VoronoiShardProxy`/`VoronoiLink`）。渲染器所有碎片网格拼进**一对**顶点/索引缓冲，`DrawItem::mesh` 只换字节偏移；`configureConvexMeshes` 初始化前调用则延迟上传，之后调用立即上传并等 GPU。TLAS 对凸网格用碎片包围盒+原旋转构造影子代理（否则单位立方体 BLAS 尺寸错）。
- 加载器把烘焙面片转三角面时**必须按记录外法线校正绕序**，否则内翻读成洞；顶点平移使质心在原点，`Pose` 只负责位姿。物理代理用平移后凸包的 **AABB** 而非烘焙 OBB——刚体没有独立于实体朝向的坐标系。
- 场景字段 `destructible.voronoi`（三处校验 + 要求 `mode:"bonded"`）；资产 `assets/voronoi/{wall-wide,wall-narrow}.voronoi.json`（48/40 单元）。
- **F4d**：UV 按实体包围盒投影（碎片与完好墙采样同一片纹理）；切割面单独成网格、作为第二个 pose 用更暗更粗糙的染色绘制；`voronoi.mjs bake-scene --scene` 按实体尺寸一键重烘。
- **关节进场景格式**：`Scene::joints`（按 entity id 引用刚体）、三处校验、`createJoints()`；马达/摩擦做成**速度级**（跑在 XPBD 回写之后），限位也在速度层提前刹车。踩坑：位置级马达被回写二次积分 → 闸门撞限位时角速度冲到 26 rad/s 并飞出世界；限位与马达分别计算再相加会反向过冲，必须合成一个目标角速度单次求解。
- 快照：关节只存 `broken`/`angle`，恢复时**先清空 `joints()` 再重建**，且**不存 joint id**（id 每世界分配，存了会让等价世界比对不等）。
- 证据：`reports/joint-yard/top30.png` vs `top340.png`（俯视，闸门从正对镜头转到约 85°，停在 −1.476 rad 且速度归零；门不动；吊灯悬垂）。
- 坑：整晚与并行 codex 进程抢构建锁/被 fingerprint 门禁打断；应急办法是 `-OutputDirectory build-f4`，或直接手写 clang++ 命令只编测试/主程序。

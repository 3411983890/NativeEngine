## AI 地编（关卡生成）方案
- 产出 `docs/site/content/ai-level.html`（第 22 页，导航「工具与流程 / AI 地编管线」），另加 `nav.json` 条目。`npm run docs` 重建：22 页、0 坏链、无横向溢出。
- 核心论点（用实测算出来的，不是估计）：
  - `.screen/town.scene.json` = 237 KB / 608 实体 / 120×132 m，单实体平均 205 B ≈ 57 token → 整场景 ≈ 36k token。**结论：AI 只能产出 ≤2 KB 的 MapSpec（≈500 token），不能产出场景 JSON**；迭代成本差 60 倍。
  - 实体密度 0.038 /m²；10k 上限 ≈ 0.26 km²；120 m 视距下一张 150×150 m 图 ≈ 860 实体，是舒适区。
  - `tools/town/gen-scene.mjs` 里 10 行 `buildings` 常量表就是"人类手写 spec" → AI 地编要替换的是这张表，不是场景 JSON。
- 关键事实核对：
  - 实体**无旋转**：`components.transform.yaw` 在 schema/组件注册表里存在，但 `host/`、`renderer/` 无任何消费方（只有相机 yaw）→ 所有几何轴对齐，布局必须走网格语法。
  - 地形不做第 10 种 `kind`，做成顶层 `terrain` 块（同 `lighting`/`materials` 并列）：不占实体预算、不进 TLAS、一图一块。
  - 地形接入植被**不用改散布代码**：`engine/vegetation/surface.mjs` 已留接缝（注释明写 "a terrain height field is a different adapter with the same interface"），只需 `HeightfieldSurface` + sampler 版本号。
  - 玩法可玩性**构造即满足**：lint 的 0.5 m 洪泛可达性（KEY/GOAL-UNREACHABLE）反用为求解器——取最大两个连通分量，门放在邻接边上，钥匙 A 侧、终点 B 侧。
- 门禁映射到**已有命令**：G1 validate / G2-G3 lint / G4 build / G5 --smoke --screenshot / G6 --budget / G7 determinism+replay / G8 image-regression（人 -Accept）。
- 修复原则：几何级失败由求解器自修（不回模型）；只有规格级失败（预算、密度）才回模型；schema 违规 = emitter bug，抛给工程不重试。
- 阶段：P0 规格+发射器（先复刻 town 做回归基线）→ P1 地形 → P2 骨架/结构 → P3 玩法 → P4 闭环 → P5 风格。

## 超大世界能力盘点（代码核对，纠正两处旧文档说法）
- **没有视锥剔除**：`renderer/d3d12_renderer.cpp` 全文件只有 `CullMode`（背面），grep 不到 frustum/cull；`DrawIndexedInstanced(indexCount, 1, ...)` 的 instanceCount 恒为 1。→ 每实体一次 draw + 一次 58 DWORD 根常量写。**这是所有规模化能力的第一乘数**。
- **平面 UV 不是限制**：`shaders/material.hlsl:199` `if (input.meshUv != 0) uv = input.uv / uvScale;`，`normalIndex` bit30/31 标记 mesh UV 通道；渲染器已有 `convexVertexBuffer/convexIndexBuffer` 合并池（64 MiB，`NG-E-CONVEX-BUDGET`）与 `hasTextureUvs`。任意网格 + 顶点 UV + normal/orm/emissive/occlusion 四通道**已经能跑**，缺的是资产入口与实例化。
- **OBB 几乎免费**：`engine/native/convex.hpp` 的 `Shape{center, basis, halfExtents}` 已是任意朝向盒；SAT 15 轴只需换基。真正成本在 `scene_loader` 的 AABB 语义、TLAS、lint overlap、以及布局语法的自由度。
- **heightfield 碰撞不必新写窄相**：把地形 cell 当三角形凸包喂现有 GJK/EPA 即可，宽相复用 BVH。
- 世界坐标是 float32，无相机相对渲染；场景一次性全量加载（16 MiB JSON 上限）。

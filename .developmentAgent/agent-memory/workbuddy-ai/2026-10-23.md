# 2026-10-23

## F4c 凸-凸窄相（GJK / EPA / 面裁剪）
- 新增 `engine/native/convex.hpp`（自包含，只依赖 vec3.hpp）：`Shape`（中心+正交基+半长或局部点云+三角形索引）、支撑函数、GJK、EPA、面裁剪流形。
- 返回值改成**三态** `Result{Disjoint,Overlapping,Failed}`，不是 bool：只有 Failed 才回退 SAT 盒路径。把"算法放弃"当"分离"会静默丢碰撞，当"接触"会凭空造碰撞。
- 接入 `World::collidePair`：任一方有 `hullPoints` 走凸路径；`Body`/`BodyDesc` 加 hull 指针字段；`Game` 维护与 `convexMeshes_` 平行的 `hullPoints_`/`hullIndices_`（ConvexVertex 是 32B 渲染顶点，碰撞要 Vec3 数组）。
- 接触落地抽成 `World::emitContacts`，SAT 与凸路径共用。
- 三个坑（都写进注释了）：
  1. GJK 四面体约简判据必须是「原点在哪个面的外侧」，用「最小平面距离」会让单纯形在 3/4 点间无限振荡并被判成分离。
  2. EPA 法线**不要翻转**——A⊖B 被推向 -B，最近边界本就落在 B 侧，正好是"从 A 指向 B"。
  3. 裁剪出的接触点要投影到参考面，否则浮在入射面上；另外断面网格是开放壳体，渲染器校验不能要求"封闭"。
- 量化的动机（用 `assets/voronoi/*` 实算）：碎片 AABB 体积 / 凸包体积 中位 1.97×、p90 2.84×、最大 4.21×。包围盒有完整平底且质心必在底面内 → 碎片永远站得住。
- 测试：`tests/native_convex.cpp` 8 项全解析解；`testHullCollidesAsItsShape` 断言同一四面体盒代理倾角<8°、凸包>15° 且重心更低（断言"两者确实不同"而不是"没崩"）。
- 全绿：physics / broadphase / joints / fracture / convex / destruction / simulation。
- **重要坑**：手动 clang++ 只编部分源文件时，`gameplay_bridge.cpp` 在预编译的 `build/gameplay/nativegpu-gameplay.a` 里；一旦改 `Game` 布局必须重跑 `tools/build-gameplay.ps1`，否则 syncGameplay 读错偏移直接段错误。
- 观察：凸包比 AABB 小，原来能挡住子弹的缝现在挡不住（同样的 `--shot` 从 2 个洞变成 0 个），需要瞄碎片中心。

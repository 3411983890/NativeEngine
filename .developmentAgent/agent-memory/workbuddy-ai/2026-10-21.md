## 音频系统 A0–A3 实现（host 集成完成）

- 引擎侧三个文件落地：`engine/audio/audio.hpp|.cpp`（48 kHz 混音图、6 总线、无锁 SPSC 命令环 1024、64 物理 + 1024 虚拟 voice、VBAP 7.1.2 环、程序化 HRTF、遮挡射线双缓冲、对象槽位 32、下混、BS.1770 响度、FNV-1a pcmHash）、`audio_asset.cpp`（`.ngsnd` 容器 + WAV 导入 64 相位/24 抽头 Blackman-sinc）、`audio_device.cpp`（WASAPI 共享模式事件驱动，float 检测用 `SubFormat.Data1==3` 避开 ksuser.dll）。
- 资产：`tools/audio.mjs import` 生成 `assets/audio/bank.json`（5 条，bank hash `e2b276d36617`，各 -22..-25 LUFS）。
- 场景契约三向同步：`assets/scene.schema.json` 的 `$defs.audio`/`audioEmitter`、`host/scene_loader.cpp` 解析、`engine/scene/index.mjs` 校验；`.screen/courtyard.scene.json` 与 `.screen/fogtown.scene.json` 各加 6 个发射器（ambient / door-open / key / complete / fire / blast）。
- Host 集成（`host/main.cpp`）：`--audio off|wasapi|offline`、`--audio-quality`、`--audio-layout`、`--audio-bank`、`--audio-demo`；`adoptScene` 重启循环床并发布遮挡体（碰撞体 AABB，256 上限，跳过包含听者的盒子）；监听器跟随 `eye/lookAt`；状态边沿（门/钥匙/完成）与输入边沿（F/G）转触发；`report.audio` 收据含 mixer/voices/objectAudio/device。
- 关键修复 1：`Engine::render` 按 `blockFrames` 切分设备周期（设备给 1056 帧、内部缓冲 256 帧 → 越界写导致退出码 127/heap corruption c0000374）。
- 关键修复 2：`Config::commandLeadSamples` + `Engine::setCommandLead()`。设备线程按整周期推进时钟，命令按 `nowSample` 打点会落到"过去"→ `lateCommands=2`。宿主启动设备后设 lead = `bufferFrames + 2*blockFrames`，离线固定 `2*blockFrames`。
- 关键修复 3：离线后端时钟改用仿真 dt（smoke 固定 1/60），否则两次运行采样数不同 → pcmHash 不一致。
- 关键修复 4：`startVoice` 增加逐音源响度归一化（`cfg.loudnessTargetLufs - sound.loudnessLufs`，clamp ±24 dB），此前 bank 里 -25 LUFS 的素材实际不可闻。
- 新增 `Stats::lufsShortMax`（短时响度峰值保持），因为单个安静环境音会让 integrated 永远停在 -43 LUFS，无法证明"混音可听"。
- 证据：`.incrementalTesting/core/audio.ps1` 三层共 52 项（混音器 40 项 + offline 路由 + 真实 WASAPI 端点），`npm run audio`；已接入 `.incrementalTesting/core/verify.ps1`。真实端点：48000 Hz / 2ch / 1056 帧周期 / underruns=0 / lateCommands=0 / cpuMs≈0.12。

## 音频证据收尾（59 项全绿）

- 追加 `--audio-audition <sound>`：非空间、循环、贴听者播放单个音源。理由：场景发射器按作者意图可能很远（庭院环境灯 12 m、-12 dB），用场景 sweep 的响度断言"可听"会误判；试听模式才是与场景无关的电平证明。实测 `fogtown/blast` 短时 -19.8 LUFS（目标 -16）、峰值 0.246。
- 追加 `Stats::peakMax`：`meter.peak` 每块清零（供实时电平表），报告期读到 0；单独维护会话峰值。`resetStats()` 一并清零。
- 追加"音频不改画面"门：`--audio off` 与 `--audio wasapi --audio-demo` 同一相机各截一张 640×360，SHA-256 必须相同。
- `.incrementalTesting/core/audio.ps1` 现为四层 59 项，`npm run audio` 全绿；`node --test tests/*.test.mjs` 148 项全绿。

# 烟火宿主接入与介质积分

2026-10-26，接续 [实例服务](SMOKE-EFFECT-SERVICE.md)。宿主 GPU 效果库包含 smoke 配置时创建 `GpuSmokeService`，运行时模拟后取得源场缓冲；合成器按真实消费 fence 读取标量，不回读烟场数值。图像读回仅用于截图验证。

## 资产光学参数

`smoke.optics` 可选，默认值如下；该配置也参与 cook 身份和 reset-required 判断。

```json
"optics": {
  "extinctionPerDensity": 1,
  "scatteringAlbedo": [0.65, 0.65, 0.65],
  "emissionPerDensity": 0.05,
  "emissionStartKelvin": 700
}
```

密度单位为 kg/m³。extinctionPerDensity 是 m²/kg，范围 0–1000；相乘得到每米消光系数。RGB scatteringAlbedo 各分量 0–1，乘消光得到各色散射系数。不同实例的消光、散射源和发射源分别相加，再进行一次积分；不把每个实例独立叠到最终图像上。

emissionPerDensity 的单位是线性 RGB 辐亮度·m²/kg，范围 0–1000。启用温度通道且温度达到 emissionStartKelvin（100–10000K）时，以 `(T/1000)^4` 强度和共享的 Kelvin 颜色渐变生成每米发射源；每通道源上限为 10⁶ 辐亮度/m。这是艺术映射，不是光谱 Planck 积分或真实燃烧化学。没有温度通道时不生成热发射。

## 两档共用的输入

`shaders/smoke_medium.hlsli` 定义闭合网格范围、单元中心三线性读取、边缘格钳制及光学映射。CPU/HLSL 介质结构为五个 16 字节行；最多八个源，每源只选详细 LEF 或已确认 WF 分源代理之一。整数代理通过 dimensions.w 和 optics.w 的量化比例恢复密度，浮点 LEF 沿用原布局。自动发布与选择见 [共享合同](SMOKE-SHARING.md)。

每个交换链帧索引拥有独立的八个 SRV 描述符，复用前等待该帧 fence；不用覆写仍在 GPU 使用的槽位。`prepareRead` 后将标量缓冲临时转为 pixel/non-pixel 联合只读状态，合成结束恢复求解器登记的状态。正常模拟/停止/重建仍由服务和实际队列 fence 管理资源寿命。

宿主在效果驱动之后补一次生命周期 flush，使同 tick 发出的立即 stop 在绘制前退出介质列表，不需要等待下一次游戏 tick；flush 不重新注入或推进烟场。

## 兼容档

SM 6.6 媒质合成器沿视线计算各烟场的 AABB 入口/出口，排序成最多十九个区间；每个区间同时累加背景高度雾、重叠烟场的消光、散射和发射。烟场区间按最小格长一半采样，单区间最多 64 步。光照复用兼容档的环境/主光与最多八个局部聚光近似。

对每段长度 ds，使用 `T=exp(-sigma*ds)`、`L += currentT*source*(1-T)/sigma`，零消光时取 source·ds。积分终点来自该像素的不透明深度；透明表面使用其自身深度对应的前缀积分。没有烟场时执行原有雾逻辑。

创建管线时直接查询 SM 6.6 能力，不读取尚未初始化的能力报告缓存。缺 DXC/SM 6.6 时保留原 DXBC 兼容合成器；GPU 烟火没有可用光学管线时明确报错。较低 shader model 的硬件回退本批未实测。

## Froxel 档

`CSFogInject` 保留背景雾与烟的粗光学数据，同时在烟域及其插值邻域缓存独立的 RGB 入射光。没有烟源时沿用 `CSFogIntegrate` 的原雾前缀；有烟源时由最终像素射线的 `SmokeQualityPrefix` 将背景雾、局部雾、详细烟或 WF 代理的消光/散射/发射共同积分，光照采样低频入射光缓存。透明表面也调用同一前缀函数，按各自深度裁切，不额外叠加一层烟。

粗光学注入仍对每个 froxel 深度段裁切到实际相交长度，按半格长最多八点构造平均源。最终射线将各烟域入口/出口和背景雾终点排序，按半格长、单段最多 64 点读取实际介质，一次积分全部来源。这样远处小烟域的光学厚度不会被低分辨率 XY 重建稀释；不靠提高整个网格分辨率修补。局部灯选择/几何阴影仍复用原服务，光照自身的空间/深度精度受 froxel 缓存限制。

雾历史、散射暂存、积分和新增入射光缓存使用 RGBA32F，避免高消光和发射源在半精度中溢出。入射光缓存只为配置了 GPU 烟火的质量路径建立，占用两个追加的描述符，不移动旧描述符；80×45×48 网格增加约 2.64 MiB 净负载，本机对齐后为 2,949,120 字节，计入 textureBytes。存在烟源时关闭静态雾光照历史复用；尚无烟场速度辅助重投影、前帧深度、版本/显隐历史拒绝和完整时域滤波。这是当前明确边界，不计为 D3 完成。

## 版本、证据与剩余边界

报告提供实际合成管线标志、介质数量、消费帧数、服务资源/跳步统计，以及截图所用的每源 serial/sourceTick/version。截图版本在录制截图复制时保存，不用运行结束后的累计步数推算截图密度。

`npm run smoke:host` 是独立 `build/smoke-host` 的宿主依赖和相关画面专项。夹具覆盖均匀烟盒 Beer–Lambert 透射、双源重叠、前景遮挡、Kelvin 发射、立即停止与两次重建；仅这些相关场景，不执行全量回归。宿主并行开发导致输入变化时，构建会拒绝混合来源；可用 `.incrementalTesting/rendering/smoke-host-snapshot.mjs` 冻结当前依赖后在快照中构建，通过 `-HostBuildDirectory` 和 `-SourceCapture` 验证。报告单列捕获后工作区变化，冻结结果不能冒充随后整个宿主已验证。

最新 [宿主证据](../reports/0.11.0/31c00bc53c0b/20261026T062612Z/smoke-host-evidence.json) 为 33 场景/134 光学检查通过、实际调试错误 0；[来源审计](../reports/0.11.0/31c00bc53c0b/20261026T063410Z-smoke-sharing-final/smoke-sharing-finalization.json) 为 1489 次冻结核验、1535 项检查通过，单列捕获后的并行改动。包含真实 8→1 粗投影：两档透射均 0.607843，独立参考 0.607716；关闭色调映射时也保留实际背景雾，PPLL 表面与不透明表面按各自深度处理。完整结果见 [开发记录](SIMULATION-DEVELOPMENT.md)。旧粒子体积仍是独立 legacy 路径，云仍走原有云积分；任意媒质/任意网格、温度/速度联合投影、烟自阴影/介质对灯光的遮蔽、完整动态时域、热浪、场景 SDF、玩法粗代理、动态质量和四系统性能验收仍待完成。低分辨率夹具不证明标准游戏负载性能，D 和 A–G 均继续部分完成。

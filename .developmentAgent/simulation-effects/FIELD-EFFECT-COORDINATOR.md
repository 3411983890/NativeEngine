# 粒子与烟的共同场协调器：本轮收尾

2026-10-27。接续 [双生产服务阶段](FIELD-SERVICE-JOINT-PUBLICATION.md)。本轮完成协调器、查询路由和宿主接线代码；最新宿主运行验收尚有明确缺项，A–G 总目标仍未完成。

## 已实现

`GpuEffectFields` 拥有一个有类型视觉 WF、粒子沉积、烟求解及烟共享服务。runtime 后模拟 hooks 在同一个真实 tick 完成两域准备、共同暂存/提交和分别确认；flush 只刷新生命周期。失败整批恢复，实际局部求解不重放，两个服务分别保留原延期原因。

消费者通过协调器的只读 acquire/release/view 访问共同场。生命周期刷新后，已停止而尚未提交撤销的来源按区域、读取 halo 和通道交集拒绝新视图；无关读者继续可用，已经取得的旧快照继续由真实 fence 保活。移动且仍有活实例的旧覆盖保持原延期合同。Strong/写租约不从视觉协调器开放。

关闭前先检查活动生产者、读取者、旧快照和实际 GPU 工作，拒绝时不先销毁某个子服务。保留的 runtime hooks 使用弱引用，协调器退出后明确拒绝调用。

固定预算分区覆盖粒子私有场、烟量化场、唯一 WF 和烟求解；默认上限合计 288 MiB。统计只计一次共享世界场。粒子池、光学目标、布料和水仍有独立预算，此数值不是完整引擎联合显存/帧时间验收。

renderer 已改用协调器 hooks，在实际每个模拟 tick 提交，移除帧末独立烟 WF sync；按当前视锥提供烟观察。`GpuEffectFrame` 新增共同场消费者入口，返回视图及旧视图复用登记真实帧 fence。旧的 CPU 风场桥仍独立，CPU 权威和其他场适配未因此完成。

## 验证及缺项

- [当前原生协调器](../reports/0.11.0/31c00bc53c0b/20261026T120220Z/field-coordinator-gpu-evidence.json)：3 组、103 检查、22 次 GPU 数值比较通过，实际 AMD 890M，D3D12 错误 0。覆盖同 tick 提交、固定快照预算回滚/恢复、暂停源时间、按区域/通道拒绝停止源新视图、旧视图跨已提交撤销保持不变、关闭预检和退出后 hooks 拒绝。收尾时所有原生输入、冻结来源和二进制仍匹配。
- [宿主快速检查](../reports/0.11.0/31c00bc53c0b/20261027T020115Z-field-coordinator-wrap/coordinator-wrap.json)：已编译二进制的两档实际运行均成功、D3D12 错误 0；双用途正式效果的两个 owner 进入同一 WF。两档截图透射均为 0.780392，独立量化参考为 0.781849。实际每档运行 240 绘制帧、478 模拟 tick，截图位于第 60 帧；不是整个最新工作区验收。
- 快速检查保留了两项失败：不同分项统计分别回收已完成 GPU 资源，导致较晚的总计与较早的分项对不上。renderer 已改为汇总同一组实际发布的分项数据，修正没有运行验证，未把失败报告改写成通过。
- 最新宿主重编译被并行模块阻断：`engine/native/assets/package.hpp` 从该目录引用 `../../third_party/json.hpp` 不存在。未改动这个并行资产文件。失败日志、当前路径错误和统计修正源码保存在 [收尾记录](../reports/0.11.0/31c00bc53c0b/20261027T020115Z-field-coordinator-wrap/wrap-finalization.json)。此前宿主编译后另有 7 项并行输入变化，均单列，不能把旧二进制当作当前宿主已通过。

新入口为 `npm run fields:coordinator:gpu`；未来 build/verify 已登记相关依赖和专项，但本轮没有执行全量构建、全量回归、npm test、verify 或 CI。

后续先在并行依赖恢复后补最新宿主验收及统计修正运行验证；CPU 权威/存档、GPU 页池/多级分辨率、跨系统时间预算以及其余 A–G 目标仍在原范围内。

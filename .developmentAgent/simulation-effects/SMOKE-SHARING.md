# 烟场自动共享与按源渲染选择

2026-10-26，接续 [密度数值桥](SMOKE-FIELD-PROJECTION.md) 和 [实际光学积分](SMOKE-RENDERING.md)。`GpuSmokeSharing` 从 `GpuSmokeService` 的实际输出自动管理可选密度投影、观察提升/降级和视觉 WF 发布。宿主在当前帧全部效果模拟及生命周期 flush 后同步一次；CPU 权威场没有写入路径。

当前宿主仍使用独立的烟密度视觉 WF。服务后续已新增外部共同世界场、显式物理密度通道及 prepare/stage/finish 阶段，与真实粒子沉积服务在同一 runtime tick 的原生联合验证通过，见 [生产服务共同发布](FIELD-SERVICE-JOINT-PUBLICATION.md)。renderer、全局查询路由、跨域预算及 CPU 权威仍待整合，不能把原生联合测试当作完整宿主接入。

## 数据与观察合同

共享内容是求解后的 kg/m³ Density，固定整数比例 1024，通道上限 1048576。`sourceTick`、`inputVersion` 来自实际完成录制的求解步骤；暂停、预算延期和重发不会刷新它们。`publishedInputVersion` 只在世界场事务提交并收到来源确认后推进。

生产者 `densityInput(serial)` 使用弱服务引用验证 serial、当前缓冲、tick 和 version；失效描述符在解引用资源之前拒绝。准入前不持有 GPU 缓冲；准入后由已有输入引用及真实消费 fence 保证寿命，不回读密度/温度数值。旧投影和旧 WF 视图仍是独立不可变版本。

观察输入包含 worldVisible、订阅数、优先级和显式浓度提示。宿主按烟网格 AABB 与当前视锥相交提供 worldVisible，不把镜头距离当作玩法危险的删除条件。重叠只读消费者租约也触发共享；未知页返回 Unavailable，Strong 和权威通道仍由底层拒绝。

默认沿用场控制器的分离阈值、最短本地/共享驻留。未被观察的源只登记 CPU 元数据，不建立额外量化场或 WF 页。首次有需求后才创建；降级提交确认后释放投影与量化场，之后再提升使用新的投影 source ID，效果 serial 保持不变。该操作不是烟求解所有权迁移。

当前网格支持 WF 格长的 1、1/2、1/4、1/8、1/16，原点必须对齐细格。非对齐或量化上界超出的烟源明确延期并保留私有烟场；没有静默平移烟历史。任意原点/任意比例的守恒重采样仍待开发。

## 预算、等待与事务

默认最多跟踪 8 个烟源，每 simulation tick 最多发布 4 个；提升同时受原场 promotionsPerTick 配额限制。排序先 priority 降序，再同级 pendingSince 升序，最后 serial 升序；已有共享源的新更新不会一直抢占更早等待的同优先级来源。

局部投影与 WF 的默认各 32 MiB 上限相加不超过共享服务 64 MiB 上限，包含字段/快照/读视图的真实对齐缓冲与描述符估算，不含驱动内部 PSO 开销。与烟火求解器、光学纹理、其他粒子/布料/水的联合帧时间和总内存仍是后续整合项目。元数据注册和可选局部分配在发布事务之外建立，提交回滚不使本地句柄失效。

候选在 GPU 导入/投影前核对 WF 页、来源、快照、行及字节预算。预算不足保留上次已提交状态，显式记录 pending、pendingSince、reason 和 deferredCandidates；继续尝试能容纳的其他候选。源模拟继续独立推进。恢复后提交最新实际版本，不用新位置补算旧 tick。相同输入版本重用已有投影，暂停时不重复导入。

停止/降级撤销先于普通更新。在正常新 simulation tick 中用现有原子事务撤销来源与覆盖，提交后确认并回收；提交延期不会假装来源已被世界场撤销。录制中无法恢复的错误标记 failed，要求排空重建。

## 同 tick 停止和快照

WF 不允许回改已提交 simulation tick。因此同 tick 的生命周期 flush 只标记已停止来源、阻止新查询视图，等下一次真正的新 tick 正式撤销；不会凭空制造 simulation tick 或把旧密度标成新状态。当前采用保守的服务级新视图拒绝，尚未细分为受影响区域。

已经借出的视图仍代表其显式旧版本，可以读到对应历史密度；其资源到真实读取 fence 完成后才回收。新查询在停止待提交期间得到 unavailable 原因。其他来源继续保留自身身份和贡献；最后来源撤销后，仍有消费者租约的区域可保留未知覆盖页，租约/视图退还后资源归零。

## 宿主光学选择

宿主每个 serial 每帧只生成一个光学输入。16 米以内使用详细 LEF；较远且无需温度发光的来源，只有在 WF 已提交版本与当前实际求解版本完全一致时才选其分源不可变粗投影。共享延期、版本不匹配或需要温度发光时使用当前详细场。

选择的是 WF 来源账本持有的分源密度投影，而不是把所有来源聚合成一个密度后套用某个来源的光学参数。这样不同来源的消光/散射系数仍分别正确映射；之后仍由既有统一区间/froxel 积分相加。读取整数代理时使用通道量化比例恢复 kg/m³，与浮点 LEF 共用同一光学合同。

详细场与同源代理不会同时加入列表。粗代理与详细场混合的不同来源各贡献一次；前景深度继续裁切积分。代理 SRV、像素/计算资源状态、读取 fence 和每帧描述符寿命沿用已有桥。截图记录每源 serial/sourceTick/version 和 representation=lef/wf。

质量档以 froxel 缓存入射光，最终像素/透明表面的实际射线共同积分雾与所选烟介质，避免小烟域因 XY 光学重建而变淡；实现细节见 [光学合同](SMOKE-RENDERING.md)。该光照缓存仍受既有约 96 米深度范围与空间分辨率限制，没有完成任意远距的光照误差合同。

当前 16 米切换是固定质量策略，没有渐变或可编辑 LOD；密度代理尚无温度/速度联合投影，热发射保留详细场。云、legacy 体积和任意媒质重叠还没有统一到这条来源账本；不能据此宣称 D2/D3 或整个 B/D 已完成。

## 验证入口

`npm run smoke:sharing` 是独立增量门禁，覆盖实际服务与 GPU Runtime 的发布、暂停、同 tick 停止拒绝新视图、正式撤销、旧视图、订阅/驻留/降级、配额/优先级/旧等待、公平恢复、非对齐回退、真实队列阻塞和独立尾烟。

`npm run smoke:host` 包含近处详细场、远处共享代理、两档光学、混合来源、前景深度、热发射回退、停止及重建。只构建宿主必需依赖；冻结源码构建与之后工作区修改分别记录，结果不能冒充整个随后工作区已验收。版本化结果见 [开发记录](SIMULATION-DEVELOPMENT.md)；未运行全量测试/全量回归/CI。

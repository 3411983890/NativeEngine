## 1. 用户已确认的基础版本

| 范围 | 目标 |
| --- | --- |
| 编辑视角 | 右键＋WASD 漫游、Alt＋左键环绕、中键平移、滚轮缩放、F 聚焦 |
| 直接编辑 | 在真实三维视窗中选择、移动、旋转、缩放对象，属性面板与场景大纲同步 |
| 物理对象 | 调整物体时同步更新碰撞形状，支持新增、删除模型与基础几何体 |

| 不可见对象 | 光源等使用始终面对摄像头的图标牌显示；运行时不绘制这些编辑图标 |
| 运行 | 直接在编辑器视窗内运行第三人称场景 |
| 模拟 | 提供独立的物理模拟按钮，与操控角色的运行模式区分 |

本文将“放大缩小物理”按“缩放物体，并同步其碰撞体和刚体形状”处理。物体尺寸和角色碰撞尺寸的具体映射见第 6 节。

优先修复的基础问题是：预览时钟和编辑状态没有分开、场景相机没有完整接入、草稿尚未实时进入原生预览、旋转尚缺完整持久化契约。

## 3. 典型操作流程

1. 打开项目后看到静止的编辑场景，物理方块停留在其编辑位置。
2. 自由移动视角，点击一个模型，出现高亮和移动操纵柄；大纲与属性面板选中同一实体。
3. 切换旋转或缩放工具，拖动手柄；对象、碰撞辅助线和属性值即时同步。
4. 从资源面板把模型拖进场景，显示放置预览；松手后生成一个可撤销的场景实例。
5. 多选对象、复制、吸附摆放；删除实例后可撤销恢复。
6. 编辑视窗中可以看到光源图标，点击后调整真实光照参数。
7. 点击“物理模拟”，仅观察重力和碰撞；停止后恢复模拟前位置。
8. 点击“运行”，在同一个视窗操控机器人；停止后恢复编辑相机、选择和草稿。

## 4. 编辑相机与输入规则

### 4.1 通用关卡编辑器操作

| 操作 | 行为 |
| --- | --- |
| 左键点击 | 选择对象；点击空白清空选择 |
| 左键拖动空白区域 | 框选；从操纵柄起拖则执行变换 |
| Ctrl＋左键 | 切换单个对象的选择状态 |
| Alt＋左键拖动 | 围绕选中对象或当前观察中心环绕 |
| 中键拖动 | 沿摄像机所在平面平移视角 |
| 滚轮 | 透视视图沿观察方向推近/拉远；正交视图改变可见范围 |
| 按住右键并移动鼠标 | 原地转动观察方向 |
| 按住右键＋W/A/S/D | 自由漫游；Q/E 上下移动 |
| 漫游时 Shift | 临时加速；释放后恢复基础速度 |
| F / Home | 聚焦选中对象 / 框住全部可编辑对象 |
| Q/W/E/R | 非漫游时切换选择/移动/旋转/缩放工具 |
| Ctrl＋D / Delete | 复制选中对象 / 删除选中实例 |
| Ctrl＋Z / Ctrl＋Y | 撤销 / 重做 |
| Esc | 取消本次拖拽、框选或放置，恢复操作开始前的状态 |

文本输入框、下拉框、弹窗获得焦点时不触发场景快捷键。右键漫游时 Q/W/E/R 的导航含义优先于工具切换。

### 4.2 相机要求

- 编辑相机独立于玩家位置、角色转向和游戏相机配置。
- 支持透视、顶视、前视、侧视；正交视图使用真实的正交投影。
- 相机距离、移动速度、近远裁剪平面随观察尺度调整，兼顾小物件和大场景。
- 聚焦使用对象真实世界包围盒；多选时使用合并包围盒；摄像机不落入目标内部。
- 每个打开的场景/资源预览保留自己的观察状态，保存到项目编辑器状态，不写入游戏场景。
- 切换工具、保存、热更新、调整面板大小时保持观察位置。
- 失焦、鼠标捕获丢失、弹窗出现和视口销毁时清空按键，结束漫游，取消未完成拖拽。

## 5. 选择、操纵柄与编辑历史

### 5.1 选择

- 单选、多选、框选、全选；大纲、视窗、属性面板使用同一组实体 UUID。
- 首个闭环可使用包围盒拾取；完整基础版本对静态导入模型补充三角形命中，避免空心模型的空白部分遮挡后方对象选择。
- 角色使用当前蒙皮包围盒作为选择代理，暂不将逐三角形蒙皮拾取列为基础要求。
- 默认只选择可见表面；穿透框选作为显式选项。框选规则在界面中显示，不靠隐含鼠标方向改变语义。
- 命中优先级：当前操纵柄 → 非遮挡的编辑图标 → 最近的场景实体；隐藏或锁定对象不进入可编辑选择集。
- 选中高亮、轴颜色和光照分离，暗处也能辨认；高亮不影响材质本身。

### 5.2 移动、旋转、缩放

- 移动支持单轴、平面与自由平移；旋转支持 X/Y/Z 环；缩放支持单轴、平面和统一缩放。
- 支持世界坐标与局部坐标切换，明确显示当前坐标系。
- 单选以对象枢轴为中心；多选默认以选择集中心为中心，活动对象枢轴作为可切换选项。
- 移动、角度、缩放吸附分别配置；建议初始值为 0.5 米、15 度和 10%，均可调整或关闭。
- 屏幕中操纵柄保持适当大小；在远近不同距离下都能稳定选中。
- 拖拽基于操作开始时的变换和几何约束计算，不累加鼠标采样误差。
- 拖拽过程中数值面板显示当前结果；手动输入数值也即时更新三维画面。
- 基础版本采用正尺度，禁止零尺度和镜像负尺度。需要镜像功能时另行设计法线、绕序与物理语义。

### 5.3 一次操作的事务边界

```text
开始拖拽：记录实体集合、初始变换、场景版本、会话代次
  → 多次更新预览：只改变内存草稿与原生预览覆盖
  → 松开鼠标：形成一个可撤销的本地编辑步骤
  → 保存：校验整批草稿，以 expectedRevision 原子提交

Esc / 失焦 / 捕获丢失：取消当前拖拽，恢复开始前状态
```

- 一次拖动、多对象复制或批量删除只占一个撤销步骤。
- 撤销/重做、属性修改和操纵柄共用命令历史；新操作使旧的重做分支失效。
- 明确协调未保存草稿历史与已提交场景历史，禁止一次撤销跨过用户最近的未保存操作。
- 不按鼠标移动频率写文件或重建整个游戏；轻量预览更新与保存使用不同路径。
- 外部 revision 变化时保留草稿并提示冲突；不静默覆盖外部修改。

## 6. 完整旋转与物理同步

### 6.1 变换数据设计

设计目标是位置、三轴旋转、尺寸在 JSON、编辑器、原生渲染、物理、快照、撤销和构建包中含义一致。

- 建议以归一化四元数作为唯一权威旋转数据，属性面板以度显示欧拉角。
- 建议新场景采用 `schemaVersion: 3` 与实体可保存的 `rotation: [x,y,z,w]`；具体修改必须同时覆盖场景 schema、JS 校验、原生读取、事务和包格式。
- 读取旧版 1/2 场景时，缺省旋转为单位四元数；已有 `components.transform.yaw` 按绕 Y 轴旋转迁移。
- ECS 旋转由权威实体变换生成；旧 yaw 仅作为兼容输入/派生接口，不与四元数同时独立修改。新数据出现冲突时应明确拒绝或给出迁移诊断。
- 所有旋转支持路径一起验收；不以“能画出旋转环”替代物理和保存支持。

### 6.2 尺寸含义

| 对象 | 当前语义与编辑要求 |
| --- | --- |
| 基础方块、地面、墙 | `entity.scale` 表示完整尺寸；缩放手柄按初始尺寸比例生成新尺寸 |
| 导入静态模型 | 根据导入时的本地几何与归一化范围更新实例变换；不修改共享导入包或其他实例 |
| 机器人等角色 | `character.scale/offset` 控制可见模型，`entity.scale` 控制碰撞尺寸；整体缩放时两者同步，不能只改变碰撞代理 |
| 有骨骼的角色 | 基础版本优先统一缩放；非等比缩放在骨骼/蒙皮支持完成前明确限制 |

### 6.3 碰撞和刚体

- 编辑预览同步更新可见网格、碰撞代理、宽相位包围盒和可选的碰撞辅助线。
- 旋转后的方块使用具有正确朝向的碰撞形状；世界 AABB 仅用于粗筛，不代替最终窄相位形状。
- 静态模型使用现有受支持的碰撞代理类型；不能把任意导入三角网格宣称为动态精确碰撞。
- 刚体缩放后重新计算形状和惯性，基础版本保持用户设置的质量，避免尺寸改变时质量规则不透明。
- 编辑模式不推进物理；模拟模式中的结构修改先暂停，在固定步边界应用并重建受影响数据，再明确恢复模拟。
- 删除动态实体时一并清除碰撞体、约束/触发关联、选择代理和辅助图标。
- 质量、摩擦、弹性、静态/动态类型和碰撞开关应能在属性面板编辑。
- 不支持的变形、过小尺寸或非法旋转应阻止提交并定位字段，不能显示已成功却仍使用旧碰撞体。

## 7. 新增、删除与模型实例

### 7.1 基础版本入口

- 创建菜单：方块、平面、光源；其他几何类型随原生几何支持开放。
- 资源面板：将已导入模型或基础机器人拖入场景，或点击“添加到场景”。
- 放置预览：根据鼠标射线与场景表面求交，显示半透明实例；没有命中时落到当前工作平面，并显示该状态。
- Esc 取消放置；点击/松手确认；实例采用新 UUID 和可辨认名称。
- 复制复用不可变的网格、纹理和动画资源，生成独立实体，不复制整份资产包。
- 删除仅删除场景实例；删除资源文件是独立操作，需先检查引用。
- 保留当前场景对玩家和地面的必要约束。删除最后一个必要实体前提示具体原因，不能直到运行时才失败。

### 7.2 状态与引用

- 新增、复制、删除后，原生画面、大纲、资源引用、选择集和撤销历史同步更新。
- 大纲隐藏/锁定属于编辑状态，默认不等于关闭对象在游戏中的可见性或逻辑。
- 导入和依赖写入当前项目 `assets/`；场景保存到 `.screen/`；不能写入引擎源码目录。

## 8. 不可见对象的图标牌

### 8.1 显示原则

“贴纸”在这里指面向摄像机的图标牌（billboard），不指投射到墙面/地面的材质贴花。

- 编辑模式中为光源绘制灯泡/太阳等图标；图标朝向当前编辑摄像机。
- 以固定屏幕尺寸为主，避免远处不可选、近处遮满画面；选中时可显示名称与参数范围。
- 点光源显示作用半径；聚光灯显示锥体；方向光用箭头表达方向，图标仍面对摄像机。
- 图标尺寸不等于光源强度或范围；物理缩放操作也不应意外修改光照强度。
- 图标可点选，对应真实实体 UUID；图标范围和几何命中使用同一相机、视口尺寸与 DPI。
- 图标被场景遮挡时建议减淡显示；完整遮挡/穿透选择策略列入待确认细节，不把“面对摄像机”解释为必须完全穿墙显示。
- 提供“辅助显示”开关，统一控制图标、碰撞线、网格、范围线和操纵柄；可选的纯净预览隐藏这些辅助元素。

### 8.2 运行边界

- 图标、范围线、选择高亮和操纵柄属于编辑器专用绘制列表，不是游戏实体或资产实例。
- 运行画面和最终游戏截图不提交编辑辅助绘制；图标不进入碰撞、阴影、反射或全局光照贡献。
- 光源的照明效果继续生效；去除的是占位模型和辅助图标。
- 有实际可见灯具模型时，灯具网格正常渲染，灯光图标仍只出现在编辑视图。
- 删除光源等对象时，不遗留图标或拾取记录。
- 音源、出生点、相机、触发区与特效发射器可复用此机制，具体类型随用户确认扩展。

由于当前使用原生子窗口，操纵柄、框选和图标应在原生视口中绘制。不能依赖普通 HTML 层必然覆盖 HWND。

## 9. 编辑、物理模拟和视窗内运行

| 状态 | 摄像机与输入 | 时间推进 | 场景修改 |
| --- | --- | --- | --- |
| 编辑 | 编辑相机；选择和操纵柄 | 不推进游戏物理；动画/特效资源预览使用单独时钟 | 修改编辑草稿 |
| 物理模拟 | 编辑相机；观察刚体 | 推进物理，不消费玩家操控输入 | 基础版本先暂停再修改结构 |
| 模拟暂停 | 编辑相机 | 暂停；支持固定物理步单步 | 允许修改模拟实例 |
| 运行 | 游戏相机；WASD、Shift、跳跃等游戏输入 | 推进游戏、动画、物理和相应音频 | 编辑工具退出输入接管 |
| 运行暂停 | 暂停游戏输入 | 暂停；保留当前状态 | 显示运行状态，不自动写回 |

### 9.1 进入与退出

1. 进入模拟或运行前，冻结一份完整、校验通过的有效编辑场景（已保存数据＋草稿），记录原生资源版本。
2. 记录编辑相机、选择集、工具、草稿和编辑历史。
3. 在同一视窗切换到独立运行实例；进入运行模式时隐藏所有编辑辅助图形。
4. Shift＋F1 释放游戏鼠标/键盘接管，保证仍可点击暂停和停止；重新点击视窗可继续接管。
5. 停止销毁运行实例，恢复原来的编辑场景、相机、选择和历史。

停止操作默认丢弃物理/游戏产生的位置和状态，不自动保存回编辑场景。“应用模拟结果”作为待确认扩展，须提供差异预览和独立撤销步骤。

运行前不强制偷偷保存草稿。项目仍显示未保存状态；运行实例仅使用校验后的内存快照。独立运行窗口可保留为辅助测试入口。

### 9.2 特殊情况

- 切换项目、关闭场景、设备重建时先结束运行会话，并保留可恢复的编辑草稿。
- 弹出对话框或窗口失焦时释放输入，清空按键，避免恢复后继续移动角色。
- 模拟与运行不能同时推进同一个刚体世界；切换前先停止当前模式。
- 错误回报带场景、实体和阶段信息；运行启动失败后仍返回可编辑状态。

## 10. 实现模块与通信契约

### 10.1 模块划分（拟新增/扩展）

| 模块 | 职责 |
| --- | --- |
| 原生编辑会话 | 编辑场景、预览覆盖、会话模式、资源生命周期、选择集 |
| 编辑相机 | 导航、投影、聚焦、相机版本、DPI/resize 同步 |
| 拾取与操纵柄 | 射线、几何/图标命中、变换约束、框选与选择高亮 |
| 编辑辅助绘制 | 图标牌、网格、轴、轮廓、光照范围、碰撞线 |
| 编辑命令历史 | 多对象原子操作、撤销/重做、取消、保存与冲突处理 |
| 预览模式控制 | 编辑/模拟/运行实例、独立时钟、暂停、单步和状态恢复 |
| Electron/页面桥接 | 工具状态、受控命令、原生事件、大纲和属性同步 |

生产模块优先放在 `engine/native/editor/` 或现有宿主边界内，UI 留在 `editor/`；具体拆分在 M0 固定，不将逻辑全部追加到 `host/main.cpp`。

### 10.2 拟议消息类别

`setCamera`、`setProjection`、`focusSelection`、`setSelection`、`setTool`、`beginTransform`、`updateTransform`、`endTransform`、`cancelTransform`、`setMode`、`pause`、`step`、`stop` 是拟议协议名称，当前尚不存在。

- 相机、变换消息带 sessionId、projectId、baseRevision、sequence 和视口代次；选择带实体 UUID。
- 拾取携带相机/画面版本；resize 或相机改变后，不用旧坐标直接决定新选择。
- 输入在原生 HWND 获得焦点时进入同一编辑会话；页面控件发出的命令也必须走相同的状态机。
- 新协议采用有长度和数量上限的结构化消息，定义消息版本、限流、超时和断连恢复；不把当前短文本管道无约束地扩展为大段 JSON。
- 高频更新合并旧状态，仅保留最新预览；开始、结束、取消等事务消息不能被合并丢失。
- ACK/事件回报已应用的序号、真实变换和失败原因；界面区分“正在应用”“草稿”“已保存”。
- 路径限制在当前项目或明确授权的只读引擎内置资产目录。原生回报不作为任意路径写入指令。

以下是同一个基础版本的内部里程碑，不把已确认的功能拆成未承诺的远期目标。没有在实测前承诺工期。

## 12. 增量验收

### 12.1 必须覆盖的场景

1. 空白编辑视口、基础机器人场景、多个模型、多个光源与动态方块。
2. 切换相机、滚轮、漫游、F 聚焦；100%、150%、200% DPI 与面板 resize 后拾取正确。
3. 单选/多选/框选、遮挡、空白点击，视窗与大纲一致。
4. 拖拽 100 次预览更新只产生一个撤销步骤；Esc、失焦和捕获丢失能完整还原。
5. 三轴旋转/缩放后保存、重新打开、构建运行，与编辑结果一致。
6. 静态体、动态体和角色整体缩放后，模型、碰撞体、接触面一致。
7. 复制/删除后撤销与重做，实体 ID、引用和物理注册不冲突。
8. 图标随相机转动保持正面，点击命中对应实体；运行画面无图标、手柄、范围线和光源占位方盒。
9. 编辑状态等待 10 秒，方块不下落；模拟会下落；停止后回到编辑位置。
10. 视窗内运行可行走、奔跑、跳跃和碰撞；停止恢复相机、选择、草稿和历史。
11. 外部场景修改、无效数值、断连和资源丢失时保留草稿，并显示真实状态。
12. 旧版场景兼容；项目资源、报告、构建、保存不写回引擎源码。

### 12.2 测试与文件规则

- 相机、拾取、操纵柄、历史与视口协议的新增验证入口放入 `.incrementalTesting/editor/`。
- 旋转/碰撞专项放入 `.incrementalTesting/simulation/`；资产路径与导入回归沿用资产增量范围。
- 需要原生资产绘制时使用独立的 `build/assets-host`；编辑视口自身构建复用 `build/viewport-host`，不污染其他专项产物。
- 测试场景源放 `.screen/`；临时场景放专用 `build/` 或系统临时目录，结束清理。
- 真正创建的运行时项目、运行画面和验收报告放 `%USERPROFILE%/Documents/nativeEngineProject/<项目名>/`。
- 新增入口时同步 `package.json`、CI 对应配置、`.incrementalTesting/commands.json` 与命令索引。
- 每个阶段仅运行其依赖范围的增量测试；未经新的明确要求不运行全量测试、`npm test`、`npm run verify` 或完整 CI。
- 本轮只新增 Markdown 并检查链接/索引，不执行功能构建或运行时测试。

协议与边界：

- `preview` 只接受有限数值、正尺度（0.001–10000）和现有实体 UUID；未知键仍被忽略。
- 覆盖是相对授权变换的差值，复合姿态（车辆部件、破碎单元）保持内部相对关系。
- 覆盖不更新碰撞体、宽相位或物理注册，也不写回场景；这些属于 M3。
- `run` 目前只切换游戏相机并推进游戏，不接管 WASD/跳跃输入；视窗内运行属于 M6。
- 新建实体在保存前不会出现在原生视口；保存后由重新打开的场景生成。
- 尚未实现：拾取/框选/多选、操纵柄、完整四元数旋转与 schema v3、碰撞体同步、光源图标牌、运行输入、每场景相机持久化。

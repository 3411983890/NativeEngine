# 功能覆盖与证据

引擎版本以 project.json 与包内 manifest.json 为准。此表覆盖本示例实际使用的能力，不等同于引擎全功能验收。

| 能力 | 覆盖位置 | 验证 |
| --- | --- | --- |
| 第一人称、碰撞、视线交互 | 全程、仓库入口 | 原生通关、镜头高度、遮挡和画面检查 |
| Lua、显式状态、事件 | 全部交互与任务 | 原生运行无脚本诊断 |
| 多实例门锁与背包 | 两把钥匙、仓库、维修柜 | 两把独立钥匙、不同条件的门 |
| 真实推箱、组件组合 | 仓库木箱与黄色压力板 | 真实移动输入推动木箱、同板开双门 |
| 原生破坏与刚体 | 维修院三段塌方 | fractureCount、碎片、破坏状态断言 |
| 顺序与重试 | 广场三节点 | 错序复位后正确通关 |
| 独立计时器 | 信号塔 | 真实超时、重试、成功取消计时器 |
| 材质、雾、局部灯、阴影 | 全镇与供能过程 | arrival/repair/square/complete 原生截图及 GPU 报告 |
| 中文 HUD、提示、音效 | 全程 | 截图包含 GPU 合成 HUD；五段原始 PCM 提示音 |
| 存档与模拟恢复 | 工具取得后、关卡阶段、快速保存 | 新 Game 加载及后续逐帧摘要比较 |
| 固定输入复现 | 全流程 | 清空游戏后重放相同输入，最终摘要一致 |
| 开发者导览 | 四个完整检查点 | F2 加载由验证流程产生的完整模拟状态 |
| 独立打包 | Windows x64 包 | 从包目录隐藏运行原生程序，校验文件哈希 |

自动报告 `reports/fogtown/evidence.json`，原生画面与性能 `reports/fogtown/render-*.json`。正常速度人工通关在报告中单独记录，不以自动加速输入代替。

脚本热重载、事务撤销、错误隔离、动画系统等既有能力仍由工程原有测试覆盖。此示例未新增这些能力的完整专属验收，参见 known-limitations.md。

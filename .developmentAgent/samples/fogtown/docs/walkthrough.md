# 游玩路线

1. 镇口：点击画面，走向值守亭，对准值守员按 E，获得仓库钥匙。绕过亭子的西侧，前往左侧仓库。
2. 仓库：按 E 开正门。站在右侧木箱后面，向仓库深处推，将箱子放上黄色压力板。后室闸门和侧窗闸门一起升起。进入后室，对准工具箱按 E；旁边还有一把独立的备用钥匙，可开广场右侧维修柜。
3. 维修院：由仓库正门返回主街，向信号塔方向前进。对准道路右侧红色起爆器按 E，塌方会真实破碎并产生刚体碎片。等碎石散落，或跳过较小碎片，再修复左侧发电机。老街灯光恢复并保存检查点。
4. 广场：先开蓝色水井节点，再开金色钟楼节点，最后开绿色风车节点。错误顺序会清空三节点，可立即重试。成功后广场灯亮起，前方信号塔闸门自动开启。
5. 信号塔：在启动控制台按 E，45 秒倒计时开始。依次连接西侧、东侧、塔基终端。超时后已完成供能保持，回启动控制台即可再试。成功后信标和塔区灯光亮起，出现完成结果；回镇口再次交谈有结局台词。

界面显示目标方向、距离、当前任务、持有装备和交互提示。F7/F12 可保存和恢复当前精确状态，包含进行中的倒计时。

# 已知限制

- 本次交付为五区域可通关的第一人称垂直切片；未宣称达到方案中完整 15–20 分钟内容量。正常探索时长需要人工实测。
- 场景沿用当前引擎的方盒几何与已烘焙材质，NPC 为组合模型，没有人物配音、专门的 NPC 骨骼动画或摄影测量资产。玩家全身动画在第一人称视图隐藏。
- 受控爆破使用真实原生破坏与碎片刚体；无新增体积爆炸烟尘模拟、受损车辆玩法或战斗。
- 地图边缘由墙体封闭，活动范围由 camera.worldExtent 限制；没有新增流式开放世界。
- 照明使用现有引擎质量路径，质量档、硬件与场景内容影响性能；未锁定目标硬件的帧率门限。GPU 雾、云、灯光历史与音频不参与玩法确定性保证。
- 相同输入复现和快照续跑仅承诺同机、同构建和同内容；改变脚本、组件或场景后旧存档会被明确拒绝。未实现跨版本进度迁移。
- 导览包括实体侧栏、已有诊断、实时报告和完整检查点，尚未制作专门的组件图形编辑器或全部功能位置标注。
- 尚未完成方案提出的全部引擎功能逐项覆盖、热重载迁移专属关卡、GPU 性能预算门禁及正常速度人工游玩验收。当前证据只陈述已运行的检查。
